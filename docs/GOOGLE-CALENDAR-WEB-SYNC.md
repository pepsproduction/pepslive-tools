# เชื่อม Google Calendar กับหน้าเว็บ

หน้าเว็บดึงข้อมูลผ่าน `/api/schedule` บน Cloudflare Worker ไม่เพิ่ม D1, KV, R2 หรือบริการ Cloudflare แบบคิดเงินเพิ่ม โดย Worker cache ผลลัพธ์ไว้ 2 นาที และหน้าเว็บที่เปิดอยู่จะตรวจคิวใหม่ทุก 2 นาที รวมถึงตรวจอีกครั้งเมื่อกลับมาเปิดแท็บ

## สถานะปัจจุบัน

Worker `pepsproduction-home` เผยแพร่พร้อม API route แล้ว และ `GET https://pepsproduction.com/api/schedule` ตอบ `connected: true` ในการตรวจเมื่อ 27 ต.ค. 2026 โดย Secret `GOOGLE_CALENDAR_ICAL_URL` มีอยู่ใน Cloudflare แล้ว ค่าของ Secret ไม่อ่านหรือเก็บไว้ใน repo

## รายการที่เผยแพร่

- ซิงก์รายการงานผลิต/ถ่ายทอดสดโดยดูจากชื่อ เช่น ถ่ายทอดสด, ไลฟ์, กีฬา, ฟุตบอล, วิ่ง, ปั่น, ถ่ายภาพ หรือถ่ายรูป โดยอัตโนมัติ ไม่ต้องกรอกซ้ำในเว็บ; รายการอื่นไม่แสดง เว้นแต่ตั้งชื่อขึ้นต้นด้วย `[เว็บ] ` เพื่อเลือกเผยแพร่เอง
- หน้าเว็บแสดงเพียงชื่อคิว วัน และเวลา ไม่ส่งคำอธิบาย สถานที่ รายชื่อผู้ร่วมงาน หรือลิงก์ Google Calendar ออกไป
- ตัวกรองตัดตัวเลขราคาในชื่อรูปแบบ `17000/2000` รวมถึงข้อความระบุราคาออกก่อนแสดง; ควรตั้งชื่อคิวให้เป็นข้อมูลที่เผยแพร่ได้
- เหตุการณ์ที่ไม่ใช่งานผลิต เหตุการณ์ส่วนตัว และเหตุการณ์ที่ยกเลิกจะไม่แสดง
- เมื่อ API ใช้งานไม่ได้ หน้าเว็บใช้ข้อมูลใน `site-content.json` เป็นข้อมูลสำรอง

## ตั้งค่าครั้งเดียว

1. เปิด Google Calendar บนคอมพิวเตอร์ ไปที่ **Settings > Settings for my calendars > เลือกปฏิทิน > Integrate calendar**
2. คัดลอก **Secret address in iCal format** แล้วเก็บไว้เป็นความลับ ห้ามใส่ในแชต, source code, `site-content.json` หรือหน้าเว็บ
3. เปิด Worker `pepsproduction-home` ที่ **Settings > Variables and Secrets** แล้วเพิ่มหรือเปลี่ยน Secret ชื่อ `GOOGLE_CALENDAR_ICAL_URL` เมื่อยังไม่มี Secret หรือต้องหมุนค่าเท่านั้น
4. หากชื่อคิวไม่เข้ากลุ่มงานที่ระบบตรวจจับได้ ให้ใส่ `[เว็บ] ` หน้าชื่อเฉพาะรายการที่อนุญาตให้ผู้เข้าชมเว็บเห็น

สามารถใช้ปฏิทินหลักได้ เพราะ Worker คัดเฉพาะชื่องานผลิต/ถ่ายทอดสดและไม่ส่งรายละเอียดอื่นออกไป การใช้ปฏิทินแยกสำหรับงานที่ต้องการประกาศยังช่วยลดโอกาสเลือกรายการผิด

หากที่อยู่ปฏิทินถูกเปิดเผย ให้สร้าง Secret address ใหม่ใน Google Calendar แล้วแทนค่า Secret ใน Cloudflare ทันที
